ОПИСАНИЕ ДОКУМЕНТА: Глава 43_091test.docx
ТИП: Критический аппарат (Ground Truth)

НАЗНАЧЕНИЕ:
Этот документ служит источником "эталонных" данных для проверки качества алгоритмов. Он содержит базовый текст (M10) и список разночтений (вариантов) для других рукописей (сиглов), составленный экспертом-текстологом.

СТРУКТУРА:
Документ разбит на логические блоки. Каждый блок соответствует одной строке или стиху базового текста.

1. ЗАГОЛОВОК БЛОКА (M10):
   - Формат: `<Номер строки>. M10: <Текст строки>`
   - Пример: "43.1. M10: възвеселе высоты..."
   - Значение: Определяет контекст и базовые токены, с которыми будут сравниваться варианты.

2. СТРОКИ РАЗНОЧТЕНИЙ:
   - Следуют сразу за заголовком блока.
   - Формат: `<Лемма> ] <Вариант 1> <Сиглы>; <Вариант 2> <Сиглы>;`
   - Разделитель `]` отделяет текст в M10 (лемму) от вариантов в других рукописях.
   - Разделитель `;` отделяет разные группы вариантов друг от друга.

СИНТАКСИС И ОБОЗНАЧЕНИЯ:
   - Лемма (слева от `]`): Точная последовательность слов из текста M10, которая подверглась изменению.
   - Вариант (справа от `]`): Текст, который находится в рукописи-варианте вместо леммы.
   - Сиглы (P81, TB, MN, U3 и т.д.): Коды рукописей. Указываются в конце варианта.
   - "om.": Специальное ключевое слово (от лат. omissio), означающее пропуск текста.
     Пример: `и ѿ ] om. TB;` означает, что в рукописи TB слова "и ѿ" отсутствуют (удалены).

НЮАНСЫ И ОСОБЕННОСТИ ОБРАБОТКИ:
1. Техническая разметка (Superscripts):
   Над некоторыми словами в документе стоят цифры (надстрочные знаки). Это техническая разметка для исследователей. При программном парсинге эти цифры необходимо игнорировать (удалять), чтобы они не становились частью слова (например, чтобы "слово¹" читалось как "слово").

2. Принцип "молчания" (Implicit Equality):
   Если сигл рукописи (например, P81) НЕ упоминается в строке разночтений для конкретного блока текста, это означает, что текст в этой рукописи ПОЛНОСТЬЮ СОВПАДАЕТ с текстом M10 в этом месте. Это критически важно для восстановления полного списка операций (равенство по умолчанию).

3. Множественные варианты:
   В одной строке после `]` может быть перечислено несколько вариантов через точку с запятой.
   Пример: `възвеселе ] възнеⷭнїе TB; възвеселїе P81;`
   Здесь для TB применяется замена на "възнеⷭнїе", а для P81 — на "възвеселїе".

4. Токенизация:
   Для корректного матчинга леммы с текстом M10 используется разбиение по пробельным символам. Пунктуация, "прилипшая" к слову, считается частью токена.

ПРОГРАММНАЯ ОБРАБОТКА:
Файл обрабатывается скриптом `testing/quality/parse_apparatus.py`, который преобразует эту структуру в список операций (WordOps: replace, delete, equal).
