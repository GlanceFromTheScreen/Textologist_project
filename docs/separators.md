# Разделители текста

На страницах запуска сравнения и матрицы расстояний можно выбрать разделители. По умолчанию выбран только обычный пробел U+0020. Минимум один символ обязателен в интерфейсе и API. Произвольные символы добавляются по одному, повторения исключаются.

Разбиение происходит по любому выбранному символу. Символы разделителей и пустые элементы между последовательными разделителями не участвуют в сравнении. Абзацы остаются границами независимо от настроек. Табуляция, неразрывный пробел и знаки препинания не делят текст, если их не выбрали. Символы регулярных выражений считаются обычными символами. Невыбранные пробельные символы сохраняются внутри элементов.

Настройка общая для обеих сторон и всех алгоритмов, сохраняется в сравнении и показывается в результате. Посимвольные правила пресетов используют получившиеся элементы как контекст. Перестановки также работают с элементами, содержащими пробелы.

При экспорте сравнения с нестандартными разделителями JSON содержит объект:

```json
{"format":"textologist-comparison-v2","separators":[",",";"],"word_ops":[]}
```

Для обычного пробела сохранён старый формат массива операций. Импорт принимает оба формата. Восстановленные тексты соединяют элементы первым выбранным разделителем: это сохраняет разбиение, но не исходное количество/вид разделителей, которые алгоритм отбрасывает.

Интерфейс переведён на русский; технические обозначения JSON, PDF, (Tr) и пользовательское содержимое сохраняются. Язык документа — `ru`, даты форматируются для `ru-RU`.
