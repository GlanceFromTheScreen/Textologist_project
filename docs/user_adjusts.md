## Правила

1. Одно слово меняется максимум на одно слово
2. Изменения трех слов - это два изменения двух слов, поэтому нужно рассмотреть все возможные варианты изменений одного слова и двух слов

## Схемы для унарных операций

1. (+) -> НЕВОЗМОЖНО
2. (-) -> НЕВОЗМОЖНО
3. (eq) -> НЕВОЗМОЖНО
4. (re) -> (+, -) или (-, +)

## Схемы для бинарных операций

1. (eq, eq) -> НЕВОЗМОЖНО, нет смысла менять eq
2. (eq, +) -> НЕВОЗМОЖНО, нет смысла менять eq
3. (eq, -) -> НЕВОЗМОЖНО, нет смысла менять eq
4. (eq, re) -> НЕВОЗМОЖНО, нет смысла менять eq
5. (+, eq) -> НЕВОЗМОЖНО, нет смысла менять eq
6. (+, +) -> НЕВОЗМОЖНО 
7. (+, -) -> (re)
8. (+, re) -> (re, +)
9. (-, eq) -> НЕВОЗМОЖНО, нет смысла менять eq
10. (-, +) -> (re)
11. (-, -) -> НЕВОЗМОЖНО 
12. (-, re) -> (re, -)
13. (re, eq) -> НЕВОЗМОЖНО, нет смысла менять eq
14. (re, +) -> (+, re)
15. (re, -) -> (-, re)
16. (re, re) -> (+, re, -) ИЛИ (-, re, +)
