# Техническое задание

**Тема:** Оптимизация поиска расхождений в кириллических текстах

## 1. Цель и задачи работы

**Цель:** Разработка полнофункционального веб-приложения для автоматизированного анализа, сравнения исторических текстов и выявления разночтений с поддержкой настройки алгоритмических параметров и пользовательской классификации замен.

**Задачи работы:**
1. Ручной набор разночтений - это сложно. Мы решаем боль неудобного заполнения разночтений
   * Автоматический результат разночтений
   * Автоматическая классификация
    *Возможность ручной правки разночтений и классов 
    * Автоматический перенос пресетов на незаполненные до этого пары текстов (пресет - сохраненный набор изменений, происходивших между парой текстов)
2. Руками невозможно посчитать статистику разночтений. Мы решаем эту боль, автоматически высчитывая статистику, что позволит принимать решения о разночтениях более математично 
3. Получение метрик близости для нормализованных текстов (нормализация применяет неважные замены и считает метрику по важным заменам)
4. Транзитивная конвертация разночтений: если настроен пресет “текст 1 -> текст 2”, и пресет “текст 2 -> текст 3”, то необходимо, чтобы автоматически мог формироваться пресет “текст 1 -> текст 3” по транзитивности. Без инструмента этот процесс делается вручную => занимает очень много времени и внимания

**Задачи к реализации:**
1. Спроектировать и разработать серверную часть (backend) на Python (FastAPI) с использованием реляционной базы данных (PostgreSQL/SQLite) и ORM (SQLAlchemy).
2. Спроектировать и разработать клиентскую часть (frontend) на Node.js (Next.js, Tailwind CSS) с современным и интерактивным пользовательским интерфейсом.
3. Разработать и интегрировать изолированный алгоритмический модуль (`algo`) для токенизации и сравнения текстов (реализация алгоритмов Myers, базового Levenshtein и модифицированного Levenshtein Nested).
4. Реализовать функционал управления данными: загрузка текстов в форматах `.docx` и `.txt`, а также загрузка пользовательских шрифтов (`.ttf`, `.otf`, `.woff`).
5. Разработать систему пословной (WordOp) и посимвольной (CharOp) классификации разночтений с поддержкой пресетов, каталога классов и ручной корректировки.
6. Создать модуль расчета и визуализации матрицы расстояний между множеством текстов.
7. Разработать конвейер оценки качества (QA Pipeline) для тестирования и сравнения результатов работы алгоритмов с реальным историческим "эталоном" (критическим аппаратом).

## 2. Исходные данные к работе

1. **Данные:** Тексты исторических рукописей (например, критический аппарат `Глава 43_091test.docx` и сырые тексты рукописей `Глава 43_t.docx`).

## 3. Содержание работы

1. **Анализ и проектирование:** Обзор предметной области вычислительной текстологии, проектирование архитектуры приложения и реляционной схемы базы данных. 
2. **Разработка аналитического модуля:** Реализация алгоритмов глобального выравнивания (Myers) и алгоритма Левенштейна. Создание гибридного алгоритма `Levenshtein Nested`, в котором стоимость замены слов зависит от их посимвольной близости. Разработка функциональности для построения матрицы расстояний (Distance Matrix) для оценки степени сходства группы текстов.
3. **Разработка Backend и Frontend:** Реализация REST API, системы аутентификации (JWT + pbkdf2_sha256), бизнес-логики работы со сравнениями, каскадного удаления неиспользуемых данных. Создание интерфейсов аутентификации, рабочих панелей (дашборда), загрузки файлов, интерактивного экрана визуализации сравнения текстов (с бейджами операций), управления пресетами и словарями классов.
4. **Тестирование и валидация (QA):** Разработка Python-скриптов для парсинга критического аппарата (выделение базового текста и «истинных» операций), алгоритмического сопоставления (Matching) эталона с вычислениями системы с применением `pandas` и формирование аналитических отчетов качества.
5. **Поиск оптимальных параметров алгоритмов:** На основе собранных данный найти параметры, которые дают лусшее качество инструмента

## 4. Перечень подлежащих разработке вопросов

1. **Архитектурные паттерны:** Выбор и обоснование стека (FastAPI + Next.js), интеграция изолированного вычислительного модуля (`algo`) в веб-приложение.
2. **Моделирование данных:** Структура хранения сложных иерархических связей результатов сравнения («Текст» -> «Сравнение» -> «Операции над словами» -> «Операции над символами»).
3. **Модификация алгоритмов:** Адаптация алгоритма дистанции Левенштейна (Levenshtein Nested) для учета морфологической (или посимвольной) схожести исторической лексики.
4. **UI/UX:** Проектирование понятного интерактивного интерфейса для текстологов: визуализация различий, ручная переклассификация замен, применение глобальных и пользовательских каталогов классов.
5. **Методика оценки качества (QA):** Способы сопоставления результатов алгоритмического выравнивания с ручным экспертным аппаратом (решение проблем с дублирующимися словами в текстах с использованием кумулятивных счетчиков).
